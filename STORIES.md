## How the image is built

- `main.py` — stdlib-only renderer, writes 1024×1024 PNG to
  `/output/entry.png`. Deterministic: two runs are byte-identical.
- `tools/gen_atlas.py` — builds `atlas.bin` + `atlas.json` from real OFL
  fonts (Bodoni Moda, Libre Baskerville, Gelasio, Liberation Sans, Roboto).
  Run it once at build time; the submitted program only blits the atlas.
- All pictures (skyline, globe, thermometer, clock, seismograph, map,
  flags, plane, ship, dome) are flat vector drawings made in code.
  No external images, no faces of public figures, no slogans.
